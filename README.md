# LT Media website

This is a dependency-free implementation of the LT Media landing page and case studies page from the supplied Figma frames.

## Run it

Open `index.html` directly in a browser, or serve the folder with any static web server.

Open `work.html` for the Case Studies page.

## Included interactions

- Responsive navigation with a mobile menu.
- Anchor navigation to Services, Process, and Contact.
- Working contact modal with client-side success state.
- Fullscreen LT Media intro video preloader with a one-second Skip action and session-based playback.
- Scroll reveal animation with reduced-motion support.
- Responsive layouts for desktop, tablet, and mobile.

The logo and checkmark use the exported Figma asset URLs from the LT Media file. Those URLs are temporary Figma MCP asset links; download the assets into `assets/` and update the two references in `index.html` and `styles.css` before deploying publicly.
